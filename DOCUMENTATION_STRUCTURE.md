# Карта документації

- README.md — запуск, поведінка, API, структура коду та команди.
- AGENTS.md — правила внесення змін і перевірки для агентів.
- PROJECT_PLAN.md — мета, межі MVP, етапи та критерії готовності.
- WORK_LOG.md — підтверджена історія роботи.

Оновлюй відповідний документ разом із кодом. Команди звіряй із package.json,
конфігурацію — з .env.example; точні версії зберігає package-lock.json.
Не дублюй тут правила агента чи опис API та не записуй неперевірені результати.
